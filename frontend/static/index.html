AlbucE viewer guide

The tabs

  • Transcription: the page image beside one model's full transcription. Use the Model dropdown (top bar) to switch which model you read. Click a line to highlight its region on the image.
  • 3-way alignment: scholarly edition vs. the selected model, with colour-coded difference chips (substitution / addition / deletion / abbrev / spacing / punct). The category chips at the top are filters (click to show/hide a type). Download diffs (JSON) exports the selected model's classified discrepancies (with TEI). Switch the compared model with the top-bar Model dropdown.
  • Transcribe a page: upload a page image and run the full pipeline (segmentation → recognition) live.
  • Model compare: line-by-line side-by-side of the scholarly text and each model, with per-character confidence heat and mismatch highlighting.
  • Review & correct: a human-in-the-loop queue of every line, ranked worst-first by kraken min-confidence + kraken↔TrOCR disagreement (the lines most likely wrong). Read the crop, type the correct transcription (field starts blank — model rows are reference only, click one to copy it in), and Save (⌘/Ctrl+↵). Corrections append to a JSONL; already-reviewed lines drop out of the queue.
